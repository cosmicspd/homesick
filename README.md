<h1 align="center">homesick</h1>
<p align="center">an "advanced utility" mod for minecraft, by cosmic, for educational purposes</p>

## Setup
- official build jars & artifact builds are provided on github.
- if you wish to self-build this mod, clone the repository and run `.\gradlew build`.
- place the jar in your mods folder & profit
